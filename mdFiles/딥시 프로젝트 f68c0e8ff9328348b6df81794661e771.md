### **Description**

- 본 프로젝트에서는 Electricity Transformer Temperature (ETT) 데이터셋을 활용하여 딥러닝 기반의 시계열 예측을 모델을 학습, 구현합니다.
- 데이터셋은 1시간 간격으로 2년동안 수집된 데이터로 총 8개의 변수들로 구성되어있습니다. (date, HUFL, HULL, MUFL, MULL, LUFL, LULL, OT)
- 프로젝트의 목표는 기준 시점으로부터 96개 타임스텝(t+0, t+1, t+2, …, t+95)에 대한 예측값을 출력하는 인공지능 모델을 학습하는 것입니다.

### **Submission File**

- Sample submit.csv 파일에 주어진 timestamp 값의 일자의 00시를 기준으로 00시, 01시, 02시, …, 95시에 대한 OT 변수의 예측값을 제출.
- 예측에 사용되는 모델의 입력값은 기준일자 이전의 데이터만 사용가능 (즉, timestamp가 2018-02-01인 경우 해당일자의 00시 값부터 예측하기때문에 입력으로 사용가능한데이터는 2018-01-31, 23시 데이터까지임)

- Train/Val/Test: 60:20:20 (Build your own training/validation set)
- 2016-07-01 00:00:00 ~ 2018-06-26 19:00:00

## Input example

- Output is 96 dimensional vector
- Input is $L\times(7+k)$ matrix
    - 5: HUFL, HULL, MUFL, MULL, LUFL, LULL, OT
    - k: create your own features.
    - L: select on your own.
- e.g., If $k=5$, $L=4$
    - target date: 2018.02.01 f
    - eatures from 2018.01.31 – [20:00, 21:00, 22:00, 23:00]
