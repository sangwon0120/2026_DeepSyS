2. 테스트셋의 구성을 잘 모르겠어요.

- 요약 1. 트레이닝 데이터셋의 출력 데이터는 18.01.31 23시 데이터까지 사용 가능.
- 요약 2. 테스트 데이터셋의 입력 데이터에서는 해당 기간의 실제 데이터 사용가능 / 출력 데이터는 실제 데이터 사용 불가능

제공된 전체 데이터는 2016년~18년으로 2년간의 데이터가 주어져있지만,
테스트 데이터에서 예측을 수행해야 하는 값은 원본 데이터에포함된 가장 최근 약 4개월 18.02.01~~ 06.22분에 대한 예측값입니다.

즉, 전체 데이터에 정답 OT값이 이미 주어져있으나, 테스트 데이터셋 기간에 해당하는 데이터를 모델의 학습 데이터셋 (training set) 혹은 검증 셋 (validation set)에 사용해서는 안됩니다.

**현재 예측 시점 기준으로 96시간, 즉 4일간의 예측을 수행하므로 즉 학습 및 검증용 데이터셋에 포함될 수 있는 정답 데이터 y의 기간은 18.01.28일까지입니다.
18.01.28에 대한 예측 수행시 가장 마지막 +95시점에 대한 값이 18.01.31 23시에 해당) **

예측 시점에 18.01.29일이 포함되는 경우, 해당 예측에 대한 정답으로 18.02.01에 대한 정답 데이터를 학습하게 됨.
테스트셋 예측 시점에 대한 데이터를 같이 제공한 이유는 예측 시점 기준으로 과거 정보를 입력으로 받아 미래 값을 예측하기 때문입니다.

즉 과거 4일간의 데이터를 사용해서 미래 4일을 예측한다고 보면 예측 시점이 18.06.20일 때 18.06.16~19 일의 실제 데이터가 필요합니다.

따라서 테스트셋의 모델 입력 데이터 (출력 데이터 아님)을 구성하는 과정에서만 테스트셋 기간의 실제 데이터를 사용할 수 있습니다.
